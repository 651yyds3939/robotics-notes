## 一、硬件系统总览

机器人硬件不是机械、电机和电池的简单堆叠，而是多个预算相互制约的整机系统：

```text
任务与性能指标
  → 形态/自由度/负载/速度/续航
  → 机械结构 + 执行器 + 电气电源 + 传感计算 + 热管理
  → 样机装配与 Bring-up
  → 标定、性能、可靠性、安全与环境验证
```

典型耦合关系：

- 更高关节力矩通常带来更大的电机、减速器、电流、散热和电池负担。
- 更轻的结构有利于续航和动态性能，但可能降低刚度、疲劳寿命和抗冲击能力。
- 更高减速比可提高输出力矩，却会影响背驱性、效率、带宽和冲击耐受。
- 计算平台和传感器增加能力，也增加功耗、热量、线束和电磁兼容压力。
- URDF 中的质量、惯量、关节轴和限位必须与实物及控制配置保持一致。

## 二、指标分解与整机预算

### 2.1 从场景分解硬件指标

| 场景需求 | 需要分解的硬件指标 |
|----------|--------------------|
| 搬运/抓取 | 工作空间、负载、末端速度、定位精度、重复定位精度 |
| 行走/越障 | 关节峰值力矩、功率、腿长、足底尺寸、结构冲击与续航 |
| 人机协作 | 碰撞能量、表面圆角、夹点、柔顺性、制动与停止距离 |
| 户外运行 | 防护等级、温度范围、防尘防水、抗振和通信覆盖 |
| 长时间运行 | 电池容量、平均功耗、热稳态、耐久寿命和可维护性 |

### 2.2 必须闭合的预算

- **质量与重心**：整机、各肢体和末端质量；重心位置及随姿态、载荷的变化。
- **力矩与功率**：连续/峰值力矩、峰值持续时间、机械功率和再生能量。
- **能量**：平均/峰值功耗、电池可用能量、DC-DC 效率和目标续航。
- **热**：电机、驱动、电池、计算平台的损耗、热阻、散热路径和降额点。
- **结构**：静强度、刚度、模态、疲劳、冲击和安全余量。
- **空间**：关节包络、线束弯曲半径、连接器维护空间和散热风道。
- **成本**：BOM、加工装配、测试工装、备件和生命周期维护成本。

预算需要记录目标值、设计值、最坏工况、实测值和剩余余量，不能只在整机完成后核算。

## 三、执行器与关节模组

### 3.1 执行器选型

关节选型至少考虑：

- 连续/峰值输出力矩与速度包络。
- 电机热容量和峰值持续时间，而不只是峰值力矩数字。
- 减速比、效率、背隙、回差、扭转刚度和背驱性。
- 转子惯量、反射惯量和控制带宽。
- 轴承承载、倾覆力矩、冲击载荷和预期寿命。
- 编码器分辨率、绝对零位、冗余反馈和断电保持需求。
- 体积、质量、线缆出线、密封、润滑和维护方式。

### 3.2 典型传动取舍

| 传动 | 优点 | 主要约束 |
|------|------|----------|
| 谐波减速器 | 紧凑、减速比高、回差小 | 柔性、冲击和疲劳寿命需评估 |
| RV 减速器 | 刚度和承载能力高 | 质量、体积和成本较高 |
| 行星减速器 | 效率高、成熟、适合高动态 | 多级回差和噪声需控制 |
| 丝杠/直线执行器 | 直线输出、轴向力大 | 速度、回程间隙和侧向载荷受限 |
| 同步带/绳驱 | 可远置电机、降低肢端惯量 | 弹性、张紧、磨损和走线复杂 |

### 3.3 关节模组构成与保护

完整模组通常包含电机、减速器、轴承、编码器、驱动器、温度检测、机械限位、制动器和连接器。设计时需要明确：

- 正常工作区、短时过载区和禁止工作区。
- 位置、速度、力矩、电流、温度和母线电压保护。
- 失电后自由下落、保持姿态或抱闸之间的安全策略。
- 标定基准、拆装复位和更换模组后的参数恢复流程。

## 四、机械本体与结构设计

### 4.1 形态、自由度和布局

形态和自由度由任务决定，而非越多越好。需要联合评估工作空间、可达性、奇异位形、稳定性、质量分布、线束路径和控制复杂度。

对人形和多足平台，还需关注：

- 浮动基座、支撑多边形和足底接触设计。
- 腿部质量分布与摆动惯量。
- 躯干、骨盆和足部刚度。
- 摔倒时的结构受力路径和易损件保护。

### 4.2 材料、刚度和寿命

- 材料选择综合考虑强度、刚度、密度、疲劳、加工、腐蚀和成本。
- FEA 至少覆盖关键静载、模态、疲劳和冲击工况，并用样件试验校核边界条件。
- 控制带宽应避开主要结构模态；结构柔性需要反映到模型、滤波或控制设计中。
- 螺栓预紧、防松、轴承配合、公差链和装配变形会直接影响整机精度与可靠性。

### 4.3 防护与可维护性

- 外壳需要兼顾碰撞防护、散热、射频、传感器视场和维修拆装。
- 避免外露尖角、剪切点、夹点和可触及高温表面。
- 连接器防呆，易损模组可快速更换，常用测试点和诊断口可接近。
- 线束留出运动余量，但不能进入关节夹点、摩擦区和高温区。

## 五、电气、电源与线束

### 5.1 电源架构

典型架构包括电池包、BMS、主接触器、预充、熔断器、PDU、DC-DC、驱动母线和低压逻辑电。设计需要回答：

- 动力域、逻辑域和安全域如何隔离。
- 启停、预充、急停、充电和掉电的时序。
- 峰值负载时的压降、纹波和欠压保护。
- 制动/下坡产生的再生能量如何吸收。
- 单点短路、接反、绝缘故障和接地故障如何隔离。

### 5.2 电池与 BMS

- 根据任务循环计算可用能量，而不是直接使用标称容量。
- 校核持续/峰值放电倍率、电芯温升、压差和老化降额。
- BMS 监测电压、电流、温度、SOC、SOH、绝缘和故障状态。
- 电池机械固定需要承受运动冲击，并考虑热失控隔离、泄压和快速拆换。

### 5.3 线束与连接器

线束是常见整机故障源，应建立独立的线束图、BOM 和检验规范：

- 导线载流量、压降、屏蔽、双绞和接地策略。
- 运动弯折寿命、最小弯曲半径、应力释放和拖链布局。
- 动力、编码器、通信和射频线缆的空间隔离。
- 连接器额定电流、锁止、防呆、防护等级和插拔寿命。
- 线号、端口、方向和检验记录可追溯。

## 六、热设计、EMC 与环境适应性

### 6.1 热设计

建立从发热源到环境的完整热路径：芯片/绕组 → 壳体/冷板 → 风道/液冷 → 环境。验证典型工况和最坏工况下：

- 电机、驱动、电池和计算平台是否达到降额温度。
- 风扇堵转、过滤网积尘或环境温度升高时如何降级。
- 温度传感器的位置能否及时反映真正热点。
- 热膨胀是否影响编码器、轴承预紧和结构精度。

### 6.2 EMC/ESD

- 动力开关和电机电缆是主要干扰源，传感器、编码器和通信是敏感对象。
- 通过接地、屏蔽、滤波、布线分区和共模抑制降低传导与辐射干扰。
- 验证 ESD、EFT、浪涌、电压跌落及电机启停对整机的影响。
- 出现通信丢包或传感漂移时，应同时排查电源完整性和 EMC，而非只改软件。

### 6.3 环境与耐久

按 ODD 选择温湿度、振动、冲击、跌落、粉尘、防水、盐雾和连续运行试验。试验后不仅检查“能否启动”，还应复测结构间隙、零位、噪声、温升和任务性能。

## 七、模型、标定与数字线程

### 7.1 实物与数字模型一致性

CAD、BOM、URDF/MJCF、控制配置和训练资产需要共享统一的：

- link/joint 名称与顺序。
- 关节轴、零位、方向、限位和传动比。
- 质量、重心和惯量。
- 传感器与末端安装位姿。
- 碰撞体和接触参数。

### 7.2 标定项目

- 关节机械零位和编码器偏置。
- IMU 安装姿态、零偏和尺度。
- 相机内参与手眼/外参。
- 力矩、六维力和触觉零点。
- 电机参数、摩擦、刚度和阻尼。

标定结果应绑定机器人序列号、硬件版本、时间、方法、环境和软件版本。更换关节、传感器或结构件后，需要明确哪些标定失效。

## 八、样机 Bring-up 与整机验证

### 8.1 分级 Bring-up

```text
不上电检查
→ 低压逻辑与通信
→ 单板/单驱动
→ 单关节空载
→ 子组件/单腿/单臂
→ 受保护整机
→ 低速低能量任务
→ 额定工况与耐久
```

每一级都应定义进入条件、通过标准、故障退出条件和回退方式。首次高压上电、首次使能和首次自主运动必须采用隔离区、限能和物理保护。

### 8.2 验证矩阵

| 类别 | 典型验证 |
|------|----------|
| 几何/运动 | 尺寸、公差、工作空间、干涉、限位、重复定位 |
| 力学 | 静载、刚度、模态、冲击、疲劳、跌倒/碰撞保护 |
| 执行器 | 力矩-速度、效率、温升、回差、噪声、寿命 |
| 电气 | 功耗、压降、纹波、绝缘、短路、启停与急停时序 |
| 热与环境 | 热稳态、降额、振动、温湿度、防尘防水 |
| EMC | 辐射/传导、ESD、EFT、浪涌和电压跌落 |
| 整机任务 | 负载、速度、续航、成功率、可用率与长稳 |

## 九、制造、装配与质量控制

- 设计评审覆盖 DFM/DFA/DFT：可制造、可装配、可测试。
- 关键尺寸、紧固力矩、胶水、润滑和线束工艺写入装配 SOP。
- 建立来料检验、过程检验、终检和出厂测试，并保存序列号与测量记录。
- 对关键件管理批次、供应商变更和替代料验证，避免同型号不同批次行为漂移。
- 通过失效件分析和现场数据更新设计规范、测试用例和备件策略。

## 十、最小交付物与检查表

### 10.1 核心交付物

- 整机硬件架构图和接口控制文档。
- 质量、力矩、功率、能量、热和成本预算。
- CAD、工程图、BOM、URDF/MJCF 和版本对应关系。
- 电气原理图、PDU/电源树、线束图和端口表。
- 标定包、装配 SOP、检验规范和测试报告。
- 风险清单、维护手册、备件清单和变更记录。

### 10.2 设计冻结前

- [ ] 任务场景已分解为可验证的硬件指标。
- [ ] 连续工况、峰值工况和故障工况均完成预算。
- [ ] 结构、执行器、电源、热、线束和控制模型完成联合评审。
- [ ] 易损件、维护空间和标定基准已设计。

### 10.3 整机验收前

- [ ] 实物、BOM、URDF、控制配置和标定版本一致。
- [ ] Bring-up 按级完成并保留原始记录。
- [ ] 安全、环境、EMC、耐久和任务测试达到项目阈值。
- [ ] 已知问题、设计余量、使用边界和维护要求已交付。
